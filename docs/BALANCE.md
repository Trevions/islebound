# ISLEBOUND — Баланс и изчисления

Всички числа са в `src/data/balance.js`. Симулаторът `tools/balance.mjs` изиграва 360-те нива с модел на „типичен играч“ и отпечатва кривите по-долу. Промениш ли число, пусни отново:

```
node tools/balance.mjs
```

## Формули

| Величина | Формула | Ниво 1 → Ниво 360 |
|---|---|---|
| Живот на враговете | 1 + 0.015 · (g − 1) | 1.00 → 6.39 |
| Щета на враговете | 1 + 0.009 · (g − 1) | 1.00 → 4.23 |
| Честота на поява | (1.2 + 2.8 · p) · (1 + 0.0035 · (g − 1)) врага/сек | 1.2 → 9.1 |
| Макс. врагове на екрана | 70 + g / 4 | 70 → 160 |
| Растеж на живота вътре в спускането | 1 + 0.6 · p | до +60% |
| Продължителност | 60 + 120 · (s − 1) / 29 сек | 60 s → 180 s във всеки свят |
| Опит до следващо ниво L | 2 + 3L + 0.5L² | 6, 10, 16, 22 … 82 (L=10) |
| Монети | (убийства · 0.35 + 15 + g · 1.2) · бонус | при загуба ×0.4 |
| Парчета остров | звезди + 2 за Пазител | 0–5 |
| Цена на сграда | основа · 1.6^ниво | 10 нива на сграда |
| Врата на свят | предишният свят е минат **и** ★ ≥ свят · 30 · 1.6 | тоест средно 1.6★ на ниво |

*g* е глобалният индекс на нивото (1–360), *s* е нивото в света (1–30), *p* е изминалата част от времето (0–1).

## Защо линейно, а не експоненциално

Експоненциалните криви създават „стени“, които могат да се минат само с плащане. Линейната крива заедно с растящата сила от острова (сгради, земи, Ехота) и новите Песни поддържа съотношението **сила / живот на врага** около 1.0 до средата на годината. Към края то плавно пада до ~0.75, така че последните светове изискват умение, Резонанси и 3★ стратегия, а не само смилане.

## Колко дълго се играе

| Съдържание | Часове |
|---|---|
| Кампания 360 нива | ~20 ч |
| Дневен свят, 365 дни | ~21 ч |
| Нощопад, 360 нива (×1.8 живот, ×1.5 щета на враговете) | ~25 ч (оценка: повече опити) |
| 3★ на всички 1 080 звезди + пълна Ехотека | ~10–15 ч |
| Безкрайна бездна | без край |
| **Общо** | **~75–80 ч**, тоест **12–13 минути на ден в продължение на година** |

Това е целевото темпо за мобилна игра: 2–4 сесии на ден по 3–5 минути.
