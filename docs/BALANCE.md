# ISLEBOUND — Баланс и изчисления (v2: 30-минутни нива)

Всички числа са в `src/data/balance.js`. Симулаторът `tools/balance.mjs` изиграва 360-те нива с модел на „типичен играч“:

```
node tools/balance.mjs
```

## Формули

| Величина | Формула |
|---|---|
| Живот на враговете по ниво | 1 + 0.015·(g−1) → ×6.4 на ниво 360 |
| Живот вътре в нивото (минута m) | 1 + 0.16·m + 0.0045·m² → ×9.85 на 30:00 |
| Щета на враговете | (1 + 0.009·(g−1)) · (1 + 0.03·m) |
| Поява | (1.1 + 0.22·m) · (1 + 0.0035·(g−1)) врага/сек |
| Макс. врагове | min(230, 60 + g/5 + 4·m) |
| Опит до ниво L | 5 + 2.2·L + 0.02·L² → ≈ ниво 60 на 30:00 |
| Цена на сграда | основа · 6 · 1.6^ниво |

**Комбо:** убийства през < 2.5 s. Всеки 25 поредни добавят ×0.1 към точките от убийства (макс ×5). Удар нулира комбото.
**Множител на нивото:** ×(1 + g/100); Нощопад ×1.5.
**Звезди:** ★ оцеляване/Пазител · ★ точки ≥ цел · ★ 3 спасени Ехота.
**Класация (all-time):** сума от най-добрия резултат на всяко ниво.
